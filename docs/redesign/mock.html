    Farhan Kurnia Febriansyah adalah mahasiswa Informatika di Universitas Muhammadiyah Malang, fokus di machine learning, statistika, dan home lab.

    Halo, saya Farhan 👋

    Kesibukan utama saya di sekitar machine learning dan statistika. Saya suka membangun sesuatu from scratch untuk benar-benar paham cara kerjanya, mengimplementasi ulang algoritma dan paper hanya dengan NumPy dan Pandas, lalu memverifikasinya terhadap hasil aslinya. Di sisi lain saya juga mengerjakan pipeline ML end-to-end untuk berbagai jenis task: sentiment classification untuk climate sustainability report, regression untuk prediksi hasil panen, sampai klasifikasi dataset kategorikal ratusan ribu baris. Kadang nyasar juga ke simulasi, dari sistem antrian sampai reaksi fisi nuklir (simplified version of course). Semua eksperimen saya tulis dalam LaTeX, dan notebook saya bahasanya campuran English-Indonesia.

    Saya juga pernah aktif di Kaliber, organisasi yang bergerak di bidang cybersecurity, sebagai anggota divisi riset dan pengembangan. Di sana saya menyusun modul pembelajaran yang memperkenalkan pentesting tools seperti sqlmap dan Burp Suite, serta membahas berbagai kelas exploit (buffer overflow, ret2win, Linux privilege escalation, XSS, LFI, dan lainnya) plus materi kriptografi. Untuk open recruitment-nya, saya mengembangkan Discord bot dengan Python yang berfungsi sebagai platform CTF (capture the flag), dan ikut menyumbang beberapa soal di kategori crypto dan reverse engineering binary Linux.

    At home, saya menjalankan homelab dari PC lama yang sudah pensiun: Intel gen 10, Proxmox, TrueNAS dengan ZFS. Karena ISP saya menaruh saya di belakang CGNAT, remote access dan deployment jalan lewat Tailscale dan Cloudflare Tunnel. Fun fact: situs yang sedang kamu baca ini berjalan di lab itu.

    Saat away from keyboard, saya biasanya di belakang kamera mempotret hal-hal random, bermain D&D dengan teman-teman, atau menulis cerita untuk kampanye D&D berikutnya.

    Self-Hosted Home Lab is Proxmox + TrueNAS SCALE on ZFS, exposed through Tailscale and Cloudflare Tunnel behind CGNAT. The infrastructure this site runs on.

    The lab runs on a Intel machine with Proxmox as the hypervisor, hosting a mix of Linux VMs and containers. Storage lives on TrueNAS SCALE with a ZFS pool

    Since the home ISP connection sits behind CGNAT, inbound access was never going to work through simple port forwarding. Tailscale handles private access to internal services, while a Cloudflare Tunnel exposes the public-facing pieces, including this very site, without opening a single inbound port on the router.

    Ongoing work includes tuning linux to work better on low memory situation (ram is expensive man 😭)

    Also this server is literally caseless, i didn't bother to buy another case xD

    Tech stack

    Proxmox, TrueNAS, ZFS, Docker, Tailscale, Cloudflare Tunnel
