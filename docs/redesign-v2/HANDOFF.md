# Redesign Handoff, v2 Design ("Preprint")

This is the **v2 design** for farhankf.my.id. It replaces the visual design in
`docs/redesign/HANDOFF.md` (v1, the wiki layout). The owner picked v2 on
15 November 2026. No site code has been changed yet.

Read this file together with v1. This file decides how the site looks. The v1
file still decides everything about the codebase: what to keep, what to
remove, constraints, known issues, and the verification checklist.

## What v2 Is

The site is typeset like a LaTeX paper, in the Gruvbox palette. Every page is
a "preprint": a centered title block, an abstract, numbered sections,
three-rule tables, numbered figures, a bibliography-style list for projects
and posts, and a footer set as footnotes. The idea comes from the owner's own
practice: the About page says every experiment is written up in LaTeX.

The paper conventions carry real content. Each one maps to a field that the
site already has. Do not add paper furniture that has no data behind it.

| `--fg` | `#ebdbb2` | `#3c3836` | Body text, table rules, footnote rule |

| `--mute` | `#a89984` | `#665c54` | The identifier only |
| `--ln` | `#bdae93` | `#665c54` | Line numbers on `--bg1` |
| `--red` | `#fb4934` | `#9d0006` | Box around internal links |

| `--aqua` | `#8ec07c` | `#427b58` | Box around external links |

Light `--mute` is `#665c54`, not v1's `#7c6f64`, because `#7c6f64` on the
light page is 4.29:1 and fails AA. Do not put `--mute` text on `--bg1` in the
dark theme (4.17:1). Use `--ln` or `--fg` there.

### Type

- Libertinus Serif, weights 400 and 700, roman and italic. Libertinus Mono
  400 for code, listings and bare URLs.
- Self-host both. `@fontsource/libertinus-serif` and
  `@fontsource/libertinus-mono` exist on npm (5.3.0 on 15 November 2026). The
  mockups load Google Fonts only because they are standalone files.
- Body 19px, line height 1.45. 18px on phones.
- Title 50px at desktop width, weight 400, centered. It scales down with the
  container to 33px.
- Section heading 23px, weight 700, with its number in front.
- Captions, tables and the author's affiliation 17 to 17.5px.
- Small caps with 0.05em tracking for the running head and the "Preprint."
  line.

### Layout

- One sheet, max width 1100px, 40px side padding (16px on phones).
- Title block and abstract are centered. The abstract is 660px wide.
- Article pages use a single text column 700px wide. Figures marked `wide`
  extend 160px past the column on each side at desktop width.
- The homepage body is two columns with a 56px gap.
- Breakpoints are container queries on the page root: 1239px (the identifier
  moves from the left edge to a line under the running head, and wide figures
  stop extending) and 760px (single column, left-aligned text).

## Shared Elements

### Running Head

One row with a 1px `--bg3` rule below: wordmark `farhankf` in bold small caps
on the left, page links in the middle, theme toggle on the right. The current
page link is `--fg0` with a 1px orange underline. Links are Home, About,
Projects, Blog, Photography. The Links page stays reachable from the footer.
On phones the links wrap to a second row under the wordmark and toggle.

The toggle is a text button that names the theme it switches to.

### Identifier

A single muted line rotated to read bottom to top, 28px from the left edge,
like the identifier on an arXiv PDF. It has three parts: the page path, a
bracketed category, and a date.

| Page | Path | Bracket | Date |
|---|---|---|---|
| Home | `farhankf.my.id/` | A fixed joke string, see Open Decisions | Last revised |
| Blog post | `farhankf.my.id/blog/<slug>` | The post's category name | `publishedDate` |
| Project | `farhankf.my.id/projects/<slug>` | `difficulty` | Year from `finishedAt` |
| Photography | `farhankf.my.id/photography` | Photo count, "10 plates" | Date range of the photos |
| Others | The page path | Omit | Last revised |

Below 1240px it becomes a normal horizontal line under the running head. It
is decoration plus metadata. Mark it `aria-hidden` only if the same facts
appear elsewhere on the page; otherwise leave it readable.

### Links

Inline links and footer links get a 1px box with 3px horizontal padding and
the normal text colour. The class decides the box colour: internal pages red,
reference numbers green, external URLs aqua. Hover fills the box with `--bg1`.
Running-head links have no box.

The owner has not ruled on whether the boxes stay. Build the box style behind
one switch (the mockup uses `data-links="colored"` on the root) so it can
change to plain orange link text without touching markup.

### Title Block

Centered, in this order: title, author name, up to two italic affiliation
lines, then one more line that depends on the page. Then the abstract: a bold
centered "Abstract" heading over justified text, followed by an optional
"Keywords:" line.

### Numbered Things

Sections, figures, tables, listings, notes and reference entries are
numbered. Generate every number on the site, with CSS counters or in the
template. Never store numbers in the CMS. Markdown `h2` headings in a post or
project body become numbered sections.

### Footer

A 200px rule in `--fg`, then footnotes at 16.5px:

1. `*` "Built with Astro + Strapi, self-hosted on Proxmox. This page was last
   revised on <date>."
2. Then a row of boxed links: About the author, Revision history, Random
   page, Links, GitHub.

The mockups use a `†` footnote to mark placeholder entries. That footnote is
a mockup device and does not ship.


## Pitfalls Specific to v2

- **Justified text.** `text-align: justify` needs `hyphens: auto`, and
  hyphenation needs a correct `lang` attribute. Much of the copy mixes
  English and Indonesian. If a block looks gappy, left align it.
- **Paragraph indents.** `p + p` is indented and paragraphs have no bottom
  margin. Lists, figures and headings between paragraphs must reset this, or
  the first paragraph after them will be indented.
- **Boxed links wrap badly.** A long boxed link that breaks across lines
  draws an open box on each line. Keep link text short, or allow
  `box-decoration-break: clone`.
- **The identifier overlaps content** between 1100px and 1240px if it stays
  absolutely positioned. The container query at 1239px prevents this. Keep
  it.
- **Small caps.** Check that the self-hosted font files include real small
  caps. If they are synthesised, they look thin; in that case drop the small
  caps and use regular caps at a smaller size.
- **Serif on a dark background** looks lighter than on paper. Do not go
  below 16.5px for any text.
- **Counters across components.** Figures and tables are numbered per page,
  across separate Astro components. Use CSS counters reset on the page root,
  or pass an index down. Test a page with two figures from different blocks.
- **Wide figures** use negative margins. Wrap the page in a container that
  does not clip them, and confirm there is no horizontal scroll at 1240px to
  1300px.
