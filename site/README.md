# Site

The Astro frontend of farhankf.my.id: server-rendered pages that read their content from the Strapi CMS in `../cms`.

```sh
npm install
npm run dev          # http://localhost:4321
npx astro check      # type-check
npm run build        # production build to dist/
```

Setup, content editing and the design system are described in [docs/development.md](../docs/development.md). Deployment is described in [docs/deploy.md](../docs/deploy.md).
